# Образцы документов

Файлы для ручной проверки и автотестов (`test/doc.test.mjs` читает их по имени).
Фикстуры `.doc` из Apache POI лежат отдельно — в `poi/`, со своими `LICENSE`,
`NOTICE` и описанием каждого файла в `poi/README.md`.
Таблицы `.xls`, `.xlsx` и `.ods` из Apache POI — в `poi-spreadsheet/`, тоже с
`LICENSE`, `NOTICE` и описанием каждого файла в `poi-spreadsheet/README.md`.
RTF, HTML, PDF, `.pptx` и `.docx` в две колонки из Apache POI — в `poi-misc/`.
Файлы под чужим расширением (книга под `.doc`, RTF под `.doc`, HTML и CSV под
`.xls`) — в `misnamed/`, с ожидаемым результатом в `misnamed/README.md`.
Отдать файлы с `Content-Disposition: attachment`, как порталы скачивания:
`node tools/serve-attachment.mjs docs 8767`.

## `.doc` в этом каталоге

Источник этих файлов в репозитории не записан. Перед публикацией репозитория
его стоит уточнить: если лицензия файла неизвестна, файл лучше заменить
образцом из `poi/`.

Признаки ниже получены разбором заголовка и структур файла, а не просмотром в Word.

| Файл | Чем сохранён | Что проверяет |
| --- | --- | --- |
| `TestWordDoc.doc` | Word 97 (`nFib=0x00C1`, без `nFibNew`) | базовый FIB Word 97, таблица, нестандартные шрифты, A4; на нём же — мутации FIB в тестах (шифрование, старая версия, битая таблица фрагментов) |
| `file-sample_100kB.doc` | сторонний генератор (`nFib=0x0101`, FIB размера Word 2002) | нестандартное значение `nFib`, текст в UTF-16, списки, таблица, гиперссылка, надпись, встроенный OLE-объект |
| `sample2.doc` | Word 2000 (`nFibNew=0x00D9`) | списки, таблица, картинки, встроенный лист Excel (поле `EMBED`), Letter |
| `sample3.doc` | Word 2003+ (`nFibNew=0x0112`) | пять разделов, JPEG, плавающие объекты, файл 1,8 МБ |
| `sample4.doc` | Word 2003+ (`nFibNew=0x0112`) | текст со стилями |
