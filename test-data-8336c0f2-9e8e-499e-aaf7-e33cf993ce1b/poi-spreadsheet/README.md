# Фикстуры таблиц из Apache POI

Книги `.xls`, `.xlsx` и `.ods` взяты из тестовых данных Apache POI без изменений.

- **Источник:** https://github.com/apache/poi/tree/trunk/test-data/spreadsheet
- **Коммит:** `ae62bb5116b9aee19ebd5834e3a82066132c9f7f` (тот же, что у `docs/poi/`)
- **Лицензия:** Apache License 2.0 — `LICENSE` и `NOTICE` в этом каталоге.

Содержимое описано по разбору SheetJS 0.20.3 (листы, ячейки, объединения, примечания, ссылки).
Колонка «Просмотр» — что показала страница просмотра в Chrome 2026-10-18: «вкладок N» — кнопки
переключателя листов (0 — виден один лист, переключателя нет).

## Чего здесь нет

- **Переименованные файлы** — сделайте сами: `SampleSS.xls` → `.doc` (должна открыться таблицей),
  `SampleSS.xlsx` → `.xls` (открывается как `.xlsx`).
- **HTML или CSV под именем `.xls`** — переименуйте `test/fixtures/orders.csv` в `orders.xls`
  (должно быть «не документ»).
