# Фикстуры `.doc` из Apache POI

Файлы взяты из тестовых данных Apache POI без изменений, кроме одного переименования (см. ниже).

- **Источник:** https://github.com/apache/poi/tree/trunk/test-data/document
- **Коммит:** `ae62bb5116b9aee19ebd5834e3a82066132c9f7f` (2026-10-05)
- **Лицензия:** Apache License 2.0 — `LICENSE` и `NOTICE` в этом каталоге.
- **Переименован:** `form-fields_International-Travel-Approval-Request-Form.doc` ←
  `au.edu.utas.www___data_assets_word_doc_0003_154335_International-Travel-Approval-Request-Form.doc`.

Признаки в таблицах получены разбором заголовков и структур файла, а не просмотром в Word:
`cx` — быстрое сохранение (`fComplex`), «фрагменты» — сколько кусков текста в таблице фрагментов
и в какой кодировке (8-бит / UTF-16), `itap` — глубина вложенности таблиц.
